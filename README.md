# Keyboard & Mouse Tester

Test every key, mouse button and the scroll wheel, right in your browser.

**Live:** https://keytester.useful-indeed.com

Keyboard & Mouse Tester shows a full-size keyboard on screen. Press each key and it turns green, so dead or unresponsive keys are easy to spot. It warns about key chatter (one press typing twice), checks how many keys your keyboard can report at once, and tests every mouse button, the side buttons, the scroll wheel and tilt. It also flags mouse buttons that double-click by themselves and estimates your mouse polling rate.

## How to use

1. Click anywhere on the page so it can listen to your keyboard.
2. Press every key once. Working keys turn green and the counter shows how many you have tested.
3. Hold several keys together to test rollover (ghosting).
4. Move into the mouse test area, click every button, scroll the wheel and move the mouse quickly to see the polling rate.

## Privacy

Everything runs in your browser. Nothing is stored. Key presses, clicks and the event log exist only in the open page and are erased when you close or refresh it.
